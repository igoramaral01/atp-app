# ATP App

App da Amaral Training Performance: planilha de treinos, programas com GIFs do ExerciseDB, calendário, feedback do aluno e gráfico de esforço.

## Rodar localmente
Crie `.env` com `EXERCISEDB_KEY=sua_chave` e rode `node server.js` (http://localhost:3000).

## Publicar na Vercel
Importe o repositório e adicione a variável de ambiente `EXERCISEDB_KEY`.
